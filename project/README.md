# 🎓 Offline Marathi Voice-Based AI Tutor for Visually Impaired Students

Fully offline voice assistant that teaches arithmetic and Pythagorean theorem
in Marathi. Supports two modes: **Arithmetic** and **Pythagoras**.

---

## Project Structure

```
project/
├── backend/
│   ├── app.py                  ← Voice loop (microphone mode)
│   ├── server.py               ← Flask web server
│   ├── math_engine.py          ← Arithmetic + Pythagoras solver
│   ├── intent.py               ← Mode-aware intent detection
│   ├── quiz.py                 ← Quiz generator (arithmetic / pythagoras-only)
│   ├── voice.py                ← Vosk STT + pyttsx3 TTS
│   ├── dataset_loader.py       ← JSONL dataset retrieval
│   └── llm_model/
│       ├── finetune.py         ← LoRA fine-tuning script  ← NEW
│       ├── inference.py        ← LLM inference + fallback ← NEW
│       └── llm_inference.py    ← Compatibility shim
├── dataset/
│   ├── marathi_math_dataset.jsonl   (2400 samples)
│   ├── pythagoras_dataset.jsonl     (20 rich samples)
│   └── merged_dataset.jsonl         (auto-generated by finetune.py)
├── frontend/
│   └── index.html              ← Browser UI with mode switching
├── requirements.txt
└── test_*.py                   ← Test suites
```

## Quick Start (No LLM — Dataset Mode)

```bash
pip install flask vosk pyttsx3 sounddevice numpy
python project/backend/server.py
# Open http://localhost:5000
```

The system works immediately using dataset retrieval — no GPU needed.

## LLM Fine-Tuning (Optional but Recommended)

### Step 1 — Install LLM dependencies

```bash
pip install torch transformers peft datasets accelerate sentencepiece

# GPU only (for 4-bit quantization):
pip install bitsandbytes
```

### Step 2 — Run fine-tuning

```bash
cd project

# Full training (~2400 + 20 samples, 3 epochs):
python backend/llm_model/finetune.py

# Quick test run (200 samples, 2 epochs):
python backend/llm_model/finetune.py --max_samples 200 --epochs 2

# Custom parameters:
python backend/llm_model/finetune.py \
    --epochs 5 \
    --batch_size 4 \
    --lr 2e-4 \
    --lora_r 16 \
    --max_length 256
```

**What happens:**
1. Merges both datasets → `dataset/merged_dataset.jsonl`
2. Downloads TinyLlama base model (~600 MB, first run only)
3. Applies LoRA (trains only ~0.3% of parameters)
4. Saves adapter to `backend/llm_model/marathi_tutor_lora/`

**Training time estimates:**
| Hardware | Full dataset | Quick test |
|---|---|---|
| GPU (RTX 3060) | ~15 min | ~2 min |
| CPU only | ~3-4 hrs | ~20 min |

### Step 3 — Test inference

```bash
cd project
python backend/llm_model/inference.py
python backend/llm_model/inference.py --prompt "पायथागोरस प्रमेय समजाव"
```

### Step 4 — Run server (LLM auto-detected)

```bash
python backend/server.py
```

The server automatically uses the fine-tuned model if `marathi_tutor_lora/` exists,
otherwise falls back to dataset retrieval.

## Mode Switching

| Say | Effect |
|---|---|
| `अंकगणित` | Switch to Arithmetic mode |
| `पायथागोरस मोड` | Switch to Pythagoras mode |

**Arithmetic mode** — all commands resolve to arithmetic:
- `पाच अधिक तीन` → calculates
- `गोष्ट सांग` → arithmetic story
- `क्विझ सुरू कर` → arithmetic quiz

**Pythagoras mode** — all commands resolve to Pythagoras:
- `समजाव` → theorem explanation
- `गोष्ट सांग` → Pythagoras story
- `उदाहरण दे` → worked example
- `तीन आणि चार` → solves c = √(9+16) = 5
- `क्विझ सुरू कर` → Pythagoras-only quiz

## Architecture

```
Voice Input (Marathi)
        ↓
  Vosk STT / Web Speech API
        ↓
  Mode-Aware Intent Detection
        ↓
  ┌─────────────────────────────────────────────────────┐
  │  Mode: arithmetic                                   │
  │    calculate  → Math Engine (deterministic)         │
  │    explain    → LLM / Dataset fallback              │
  │    story      → LLM / Dataset fallback              │
  │    quiz       → Arithmetic QuizSession              │
  ├─────────────────────────────────────────────────────┤
  │  Mode: pythagoras                                   │
  │    explain    → LLM / Dataset (rich multi-line)     │
  │    story      → LLM / Dataset (full narrative)      │
  │    example    → LLM / Dataset (step-by-step)        │
  │    solve      → Math Engine (c = √(a²+b²))         │
  │    quiz       → Pythagoras-only QuizSession         │
  ├─────────────────────────────────────────────────────┤
  │  Universal                                          │
  │    repeat     → last_response cache                 │
  │    mode switch → update session mode                │
  └─────────────────────────────────────────────────────┘
        ↓
  pyttsx3 TTS / Web Speech Synthesis
        ↓
  Voice Output (Marathi)
```

## LLM Architecture

```
Base Model: TinyLlama-1.1B-Chat-v1.0 (~600 MB)
Fine-tuning: LoRA (PEFT)
  - Rank: 8  (trainable params: ~0.3%)
  - Target modules: q_proj, k_proj, v_proj, o_proj
  - Epochs: 3
  - Learning rate: 2e-4

Dataset: 2420 samples (merged)
  - marathi_math_dataset.jsonl  (2400 arithmetic)
  - pythagoras_dataset.jsonl    (20 rich Pythagoras)

Prompt format (TinyLlama chat template):
  <|system|>
  तुम्ही एक मराठी गणित शिक्षक आहात...
  <|user|>
  {instruction}
  <|assistant|>
  {response}
```
